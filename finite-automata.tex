\begin{abstract}
\noindent Finite state automata are popular tools to analyse formal languages. This project aims to implement finite state automata, both deterministic and nondeterministic. We also implement regular expressions and generate words from their language. Finally, we implement translations between our objects and run several tests to verify our implementation. 
\end{abstract}
