\begin{abstract}
\noindent In this report we will introduce some background theory on formal languages and automata. Then we will discuss our implementation of deterministic finite state automata (DFAs), non-deterministic finite automata (($\epsilon$-)NFAs) and regular expressions in Haskell. Furthermore, we successfully implemented translations between these finite state automata and expressions and will cover those too. We designed and defined test functions to check certain properties of our implementation and of automata and regular expressions in general. All of our implementation behaves as expected. We thus created a tool that can be used to gain some understanding about automata and regular languages.
\end{abstract}
